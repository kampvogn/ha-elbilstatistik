# Elbilstatistik

Slå en dansk nummerplade op i Home Assistant: mærke, model, farve, brændstof/el og status, fra det offentlige API på elbilstatistik.dk (data fra Motorstyrelsen/DMR). Ingen ejeroplysninger.

Opsætning sker helt i brugerfladen. En gratis API-nøgle er valgfri (uden nøgle: 50 opslag om dagen; med nøgle: 3.000 om måneden). Se README for eksempler med Frigate.
